# Cinemind

A daily deduction game for film and TV fans.

Crack the case using 5 screenplay-style clues - one puzzle a day.

🔗 https://www.playcinemind.com

## About

Cinemind is inspired by Wordle. Five clues are revealed one at a time, starting with with vague scene, to ending with a direct character quote. Identify the film or TV show before you run out of clues.

The game leans into "case file noir" aesthetic, with redaction bars, wax seal & exhibit stamps, a warm amber/stamp-red palette, and a typewriter typography to make the puzzle feel like a piece of evidence pulled from a desk drawer.

A new case unlocks every day at midnight. Past cases can be revisited any time in The Vault - an archive page styled as film strips (for movies) and broadcast tape reels (for TV). The Vault stores the last 50 days worth of puzzles.

## Features
- **Daily cases** - One film and TV puzzle available per day, each with 5 progressive clues.
- **The Vault** - Archive of playable puzzles, up to the last 50 days.
- **Streaks** - Consecutive days played are tracked and highlighted.
- **Shareable results** - Shareable result grid to share the case outcome.
- **Fuzzy search** - Title searching powered by Fuse.js
